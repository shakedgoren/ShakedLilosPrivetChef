# תמונות האפליקציה

שימי כאן את כל הקבצים **בשמות המדויקים שברשימה**. הסקריפט
`scripts/seed.sh` אוסף אוטומטית כל קובץ שנמצא בתיקייה הזאת ומטמיע
אותו בקנבס — אין צורך לערוך שום דבר חוץ מלהעתיק לכאן.

## מגבלות (חשוב)
* פורמטים: `.png` `.jpg` `.jpeg` `.webp` `.svg`
* **עד ~70 KB לקובץ.** מעל 2 MB הקנבס מוחק את הקובץ בשמירה הראשונה.
  אם תמונה כבדה — להקטין לרוחב 800px ולשמור כ-WebP באיכות 80.
* שמות באנגלית בלבד, בלי רווחים.
