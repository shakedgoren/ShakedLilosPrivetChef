# תמונות האפליקציה · רשימה מלאה

כל הגדלים כאן **נמדדו מהמסכים עצמם**, לא הוערכו.
העמודה ״בתצוגה״ היא הגודל האמיתי על המסך; העמודה ״לייצא״ היא
פי שניים ממנו, כדי שהתמונה תהיה חדה גם במסכי רטינה.

## איך מעלים
1. שמים את הקובץ כאן, **בשם המדויק מהטבלה**.
2. זהו. `scripts/optimize-assets.sh` רץ אוטומטית לפני כל בנייה,
   מקטין כל תמונה שמעל 52KB ושומר את המקור ב-`originals/`.
   אפשר להעלות בגודל מלא בלי לחשוב על משקל.

פורמטים: `.jpg` לכל תמונה · `.png` רק כשצריך רקע שקוף (לוגו).

## שתי הערות

**וידאו לא נכנס לקנבס.** לסרטון בסיפור האישי צריך אחסון חיצוני
(YouTube / Vimeo) והטמעה ב-iframe — זה שייך לשלב העלייה לשרת.

**חיתוך.** כל התמונות מוצגות עם `cover` — הן ממלאות את המסגרת
והעודף נחתך מהצדדים. שווה לוודא שהעיקר של התמונה במרכז.
