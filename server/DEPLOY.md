# העלאה לאוויר · Render

## למה שורש המאגר ולא `server/`

השרת מייבא **20 קבצים מתוך `mobile/src`** — קטלוג המנות, חישוב
המחיר, חלונות המכירה ולוח השנה. אלה מקור אמת אחד לשני הצדדים,
וזו הסיבה שהמחיר שהלקוחה רואה והמחיר שהשרת גובה לא יכולים
להיפרד. לכן הפריסה חייבת לכלול את שתי התיקיות, ומכאן ה-`cd server`
בכל פקודה ב-`render.yaml`.

## הסדר

1. **Render → New → Blueprint** → לחבר את המאגר. `render.yaml`
   בשורש יוצר את השרת ואת מסד הנתונים יחד.
2. למלא את משתני הסביבה המסומנים `sync: false` (למטה).
3. פריסה ראשונה · הבנייה מריצה `prisma migrate deploy`.
4. **זריעה · פעם אחת בלבד** · מה-Shell של Render:
   `cd server && npm run db:seed`
   היא יוצרת את חשבון הניהול ואת 37 המנות עם המחירים. אין בה
   הזמנות, לקוחות או הוצאות.
5. לעדכן ב-`mobile/.env` את `EXPO_PUBLIC_API_URL` לכתובת של Render,
   ולבנות את האפליקציה מחדש.

## משתנים שצריך למלא ידנית

| משתנה | בלעדיו | סוד? |
|---|---|---|
| `CORS_ORIGINS` | שום דפדפן לא יוכל לפנות ל-API. האפליקציה הנייטיבית לא מושפעת | לא |
| `ADMIN_EMAIL` `ADMIN_PHONE` `ADMIN_PASSWORD` `ADMIN_NAME` | אין חשבון ניהול אחרי הזריעה | ⚠ הסיסמה כן |
| `GOOGLE_CLIENT_ID` | `/auth/google` מחזיר 501 והכפתור מושבת | לא · מזהה ציבורי |
| `SMTP_*` `MAIL_FROM` `APP_URL` | איפוס סיסמה לא נשלח כלל | ⚠ `SMTP_PASS` |
| `WHATSAPP_TOKEN` ומזהיו | השרת רץ, השליחות מדולגות בשקט | ⚠ הטוקן כן |

`DATABASE_URL`, `JWT_SECRET`, `TRUST_PROXY`, `NODE_ENV`, `PORT`,
`HOST` — מוגדרים אוטומטית ב-`render.yaml`.

## מה שנבדק לפני הפריסה

- `npm ci --omit=dev` · בדיוק מה ש-Render מריץ · עובר.
- השרת עולה עם התלויות האלה בלבד ומחזיר `/health` תקין.
- `NODE_ENV=production` · CORS חוסם מקור זר ומאשר מורשה, ובקשה
  בלי `Origin` (האפליקציה) עוברת.
- 91 בדיקות.

## ⚠ דברים שקל לטעות בהם

**`TRUST_PROXY=1` חובה.** מאחורי הפרוקסי של Render כל הבקשות
נראות כמגיעות מאותה כתובת. בלי המשתנה הזה הגבלת הקצב תחסום את
כל הלקוחות יחד אחרי עשר בקשות.

**`JWT_SECRET` נוצר אוטומטית, ואסור לשנות אותו אחר כך.** החלפה
מנתקת את כל המשתמשות המחוברות.

**אין `db:seed` בפריסה, בכוונה.** היא רצה פעם אחת ידנית. אילו
רצה בכל פריסה, היא הייתה דורסת את סיסמת הניהול בערך שב-`.env`.

**לא להגדיר `RESET_DEBUG`.** הוא מחזיר את אסימון איפוס הסיסמה
בגוף התשובה. הקוד כבר כובה אותו בפרודקשן, וזו שכבה שנייה.

**התוכנית החינמית של מסד הנתונים נמחקת אחרי 30 יום.** לעסק
אמיתי צריך תוכנית בתשלום, ולוודא שהגיבויים דולקים.
