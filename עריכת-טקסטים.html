עריכת הטקסטים באתר

כל הטקסטים יושבים בקובץ אחד — chef-questionnaire.html. אין צורך בידע טכני: פותחים, מחפשים את המשפט שרואים באתר, ומחליפים אותו.

לפני שמתחילים: שמרי עותק גיבוי. Finder → לחיצה ימנית על הקובץ → Duplicate. אם משהו יישבר, פשוט חוזרים לעותק.

איך פותחים את הקובץ לעריכה

  1. פותחים את היישום TextEdit (הוא מותקן בכל מק).
  2. בתפריט העליון: TextEdit → Settings (או Preferences) → לשונית Open and Save → מסמנים Display HTML files as HTML code instead of formatted text.
    בלי הסימון הזה TextEdit יציג את האתר במקום את הקוד.
  3. עכשיו: File → Open → בוחרים את chef-questionnaire.html.

אם מעדיפים כלי נוח יותר — VS Code חינמי ומצוין למטרה הזו.

השיטה — עובדת כמעט תמיד

  1. מעתיקים את המשפט שרוצים לשנות בדיוק כמו שהוא מופיע באתר.
  2. בקובץ: Cmd + F ומדביקים אותו.
  3. מחליפים רק את הטקסט שבין הגרשיים.
  4. Cmd + S לשמירה, ורענון הדף בדפדפן.
שלושה כללים:
  • לא למחוק גרשיים ' או פסיקים , — רק את הטקסט שביניהם.
  • לירידת שורה בתוך טקסט כותבים <br>.
  • אם יש גרש בתוך הטקסט עצמו (למשל בוצ׳ר) — להשתמש ב־׳ ולא ב־'.
